Interpretable speech generation & articulatory control

Research Assistant · Advised by Gopala Anumanchipalli

I build speech codecs and generation pipelines that connect audio to explicit articulatory representations, making the movements behind speech available for inspection and control.

My work spans PyTorch modeling, Dynamic Movement Primitives for articulatory trajectories, neural waveform synthesis, and reproducible training and evaluation across multiple GPUs.

UCSF2025–2026

Neural dynamics across sleep and wakefulness

Research Assistant · Advised by Joline Fan

I study how patterns of brain activity change over time using intracranial EEG. I build preprocessing and feature-extraction pipelines, then use Hidden Markov Models to investigate latent neural states.

A central part of the work is checking whether patterns remain consistent across recording nights and participants, while accounting for differences in electrode coverage and preprocessing.

Time series · Hidden Markov Models · Statistical evaluation

Conversational AI

PillarFortune

A conversational tarot application with reproducible card draws and a trained question router. I built a shared TypeScript pipeline that validates model responses against a schema for each draw, repairs invalid outputs with bounded retries, and provides a deterministic fallback.

The Cloudflare backend supports model inference, conversation memory, and persistent readings. An evaluation harness tests the same pipeline with fault injection; the browser demo runs offline and simulated engines and lets visitors inspect each step.

React · TypeScript · Workers AI · Durable Objects · D1 · scikit-learn

Model evaluation

LLM fine-tuning & evaluation

A supervised fine-tuning and evaluation pipeline for Qwen2.5 on technical multiple-choice questions. I compare LoRA adapters with the base model and profile training throughput and GPU memory.

Evaluation includes shuffled answer choices to measure option-order sensitivity, and separates invalid model outputs from incorrect answers.

PyTorch · Hugging Face · PEFT / LoRA

A Java and Spring Boot system for asynchronous task execution. I implemented priority queues and retries with RabbitMQ, stored task metadata in PostgreSQL, and added Redis caching for faster lookups.
